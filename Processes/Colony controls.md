# Colony controls

Parent: [[Processes]]

Hide colony / Show colony. The Colony window has tags: Time, Beavers, Water, Forest, Season.

- **Time** — year, month, day, what the colony is doing now, Pause, speed, Restart colony, day-of-year slider
- **Beavers** — population by stage, lodge, activity, breeding
- **Water** — dam and pond, pond rise, flow
- **Forest** — branches, trees, flood stress, regrowth
- **Season** — season name, wetland, wildlife, vegetation, snow

Restart colony restores the founding pair and autumn start. Map Stop is land scroll; Colony Pause is simulation time. Keep the 2D map stopped during a colony demo so the land does not drift.
