# Beaver colony terrain studio

Perlin-noise land, a North American riparian wetland, and a beaver colony simulation. The live app is in `my-react-app`.

**Public site:** https://mileurz.github.io/2026.9.2/

## Run the website locally

```bash
cd my-react-app
npm install
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/).

Sign-in is optional. If you use it, copy `my-react-app/.env.example` to `my-react-app/.env.local` and fill in your Firebase web app keys. Do not commit `.env.local`.

## Build

```bash
cd my-react-app
npm run build
npm run preview
```
